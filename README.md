# Leroy Ayettey | Cloud Engineer Portfolio

A modern, animated portfolio website showcasing cloud engineering projects, skills, and experience. Built with React for smooth page transitions and responsive design.

## Features

- Smooth page transitions with Framer Motion animations
- Responsive design for all screen sizes
- Navy and white monochromatic color palette
- Multi-page SPA with React Router
- Portfolio showcase with 6 featured projects
- Skills breakdown and education details
- Contact integration with email and GitHub links

## Tech Stack

- React 18 with hooks
- React Router DOM for client-side routing
- Framer Motion for animations
- CSS3 with responsive grid layouts
- Create React App setup
